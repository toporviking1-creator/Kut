# КУТ — клинически узкий таз (родблок)

Веб-приложение для родового отделения: оценка риска клинически узкого таза при поступлении и журнал функциональной оценки таза в родах по алгоритму КР «Клинически узкий таз» (Приложение Б1). На выходе — PDF-лист A4 и текст заключения для истории родов.

Данные пациенток не сохраняются и никуда не передаются: всё считается в браузере, журнал живёт до закрытия вкладки.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | приложение целиком |
| `manifest.webmanifest` | установка на экран «Домой» |
| `sw.js` | офлайн-режим (кэш) |
| `icons/` | иконки |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Публикация на GitHub Pages

1. github.com → **New repository** → имя `kut` → Public → Create.
2. **Add file → Upload files** → перетащить все файлы и папку `icons` (вместе с `.nojekyll`) → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение доступно по адресу:
   `https://toporviking1-creator.github.io/kut/`

## Установка на телефон

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

После первого открытия с интернетом работает офлайн, включая выгрузку PDF.

## Обновление

1. Заменить `index.html` в репозитории.
2. В `sw.js` поднять версию: `const CACHE = 'kut-v1.1';`
3. Commit. На телефоне обновится при следующем открытии с интернетом (иногда нужно открыть дважды).

## Настройки (в начале `<script>` в `index.html`)

- `PELVIS` — размеры таза, нормы и пороги («уменьшение ≥ 1,5 см»).
- `SIGNS` — признаки несоответствия (сверить со сноской * к алгоритму Б1).
- `HEAD` — варианты стояния головки.
- Учреждение и врач по умолчанию — атрибуты `value` полей `inst` и `doctor`.
